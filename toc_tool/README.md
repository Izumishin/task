# 総目次Excel 自動化ツール（月刊誌PDF → 総目次原稿）

老年精神医学雑誌の「年間総目次」（InDesign入稿用の元原稿Excel）を、毎月の
月刊誌PDFから半自動で作成するためのツールです。手作業でのコピペ（区分・表題・
著者・頁・掲載月・読み）を、**PDFとExcelを渡すだけ**で置き換えます。

対象列：**B=区分／C=論文表題／D=著者／E=頁／G=掲載月／I=読み（ひらがな）**
（A=共著順は転記しません。F/H の括弧、J/K の姓名分割数式は自動で付きます）

---

## いちばん簡単な使い方（推奨：毎月Claudeに頼む）

このリポジトリでClaude Codeのセッションを開き、次を添付して頼むだけです。

1. **当月号のPDF**（1冊でも、記事ごとにバラバラの複数PDFでもOK）
2. **最新の総目次Excel**（前年データが入ったままでOK）

そして「**5月号を追加して**」のように言ってください。Claudeが目次と本文を読んで
記事の骨子を組み立て、下のツールで読みを自動解決してExcelを更新し、**要確認箇所
（読みが曖昧な新規著者など）はPDFの該当ページを実際に確認**してから、更新済み
Excelを返します。前年の同じ月のデータは新しい月のデータで**置き換え**ます。

> 依頼文のテンプレートは末尾の「依頼文サンプル」を参照。

---

## 仕組み（自分でスクリプトを動かす場合）

```
pip install -r requirements.txt
```

### 1. 目次テキストとページ対応を確認
```
python add_month.py dump --pdf 当月号*.pdf
```
誌面ページ番号↔PDFページの対応表と、目次ページ（誌面p.1）の全文を表示します。

### 2. 記事の骨子を articles JSON にまとめる
目次を見ながら、記事を並び順に JSON で記述します（`sample_articles.json` 参照）。
```json
{
  "month": 5,
  "articles": [
    {"section": "巻頭言", "title": "表題", "page": 3, "authors": ["著者名"]},
    {"section": "特集", "title": "表題\n―― 副題", "page": 13,
     "authors": ["著者1", "著者2", "著者3"]}
  ]
}
```
- **section**：巻頭言／特集／原著論文／基礎講座／連載／文献抄録／書評／学会NEWS／
  調査報告／症例報告 など（Excel既存のB列表記に自動変換されます）
- **title**：目次スタイルの表題。副題（`―― …`）や目次の改行は `\n` で入れる。
  ※**文献抄録・書評は目次に表題が載らない**ので、本文ページから取る。
- **authors**：誌面の表示順に**共著者を全員**。1著者=1行に展開されます。
- **theme:true**：著者なしの特集テーマ行にしたいとき（頁・著者を省略）。
- **readings**：`{"著者名":"よみ"}` で読みを明示固定（辞書より優先）。

### 3. Excelに書き込む
```
python add_month.py write \
  --excel 総目次.xlsx --rows articles.json --out 総目次_更新後.xlsx \
  --pdf 当月号*.pdf
```
- 対象月ブロック（前年分）を新データで**置換**します。
- **読み（I列）の決まり方**：①Excel既存の全行（前年分含む）から作った
  「漢字→よみ」辞書で確定 → ②辞書に無ければ本文ページのローマ字から変換し、
  **そのセルを黄色**にして要確認マーク。外国人名はローマ字大文字のまま黄色。
- 実行後に**要確認リスト**（黄色セル）を表示します。PDFで確認して確定してください。

### 補助：特定ページの著者を確認
```
python add_month.py page --pdf 当月号*.pdf --num 73
```
誌面73ページの本文テキストと、抽出した漢字著者・ローマ字・頁範囲を表示します。

## 設計上のポイント / 既知の注意

- **PDFの分割は自由**：各ページ先頭に印字された誌面ページ番号で対応付けるため、
  記事ごとにバラバラのPDFでも、繋がった1冊でも動きます。
- **共著者の読み**：本文の記事先頭ページに漢字著者全員＋脚注ローマ字が載っており、
  それと既存Excelの読み辞書を突き合わせて決めます。常連著者はほぼ自動確定。
- **特集の総合テーマ行**の扱いは号によって揺れます（テーマを先頭記事の表題に
  兼ねる号／著者なしの独立行にする号）。**その月の目次に合わせて**記述してください。
- **読みの長音**（Koji→こうじ/こじ 等）は機械変換では確定できません。辞書に
  無い新規著者は必ず黄色になるので、必ず本文で確認を。
- **増刊号（学会抄録集）は対象外**です（紙面構成が大きく異なるため個別対応）。
- 元Excelの手入力ミス（例：福家＝ふくや を「ふくやま」等）は、辞書の多数決で
  自動的に正しい方へ寄ることがあります。差分が出たら元データ側のミスを疑って
  ください。
