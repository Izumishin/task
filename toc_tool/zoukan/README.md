# 増刊号（学会プログラム・抄録集）→ 総目次Excel

月刊号とは構成が違うため別の処理系。2026年（Vol.37 増刊号‐Ⅰ：第41回日本老年精神医学会・
第45回日本認知症学会 合同大会 JCDP2026、412頁）で初めて実施した。

## 方針（2026年にユーザーと決めたこと）

- 入れる場所：Excelの「増刊号Ⅰ目次」ブロックを置換（書式は前年の抄録集ブロックに合わせる）
- 講演・シンポジウム：演者と共著者全員（1人1行）。共催セミナーは見出し1行のみ、座長は入れない
- ポスター：**発表者のみ**（雑誌の人名索引と同じ範囲）。演題取り下げは「演題取り下げ」行で残す

## 情報源

| 何を | どこから |
|---|---|
| 演題番号・表題・演者・セッション名 | プログラム部（p.26〜110）。行の形がそろっていて解析しやすい |
| 抄録の掲載頁・共著者 | 抄録部（p.112〜402）。2段組みで1頁に2〜3演題 |
| 読みの手がかり | 巻末の人名索引（五十音順・かな見出し付き、**発表者のみ**） |

## 実行

```
pip download --no-deps jamdict-data   # 人名辞書（JMnedict入りSQLite）を取り出す
tar xzf jamdict_data-*.tar.gz && xz -d jamdict_data-*/jamdict_data/jamdict.db.xz
export ZK_PDF_DIR=<PDFのフォルダ>/ ZK_PDF_GLOB="*.pdf" JAMDICT_DB=<jamdict.db> \
       ZK_WORK=<作業フォルダ>/ ZK_EXCEL=<最新の総目次.xlsx>
python zoukan/build.py   # 演題の抽出 → sessions.json / posters.json
python zoukan/rows.py    # 行の組み立てと読み → rows.json
# 書き込みは toc_lib.write_zoukan(ws, "Ⅰ", rows, header_b)
```

`build.py` / `rows.py` には2026年号固有の手当て（番号だけの行になっていたP025、
カタカナ4語の演者P056、所属が名前に続いていた3件、カナ外国人名の読み）が入っている。
来年は同じ箇所を見直すこと。

## 読みの決め方と限界

1. 既存Excelの辞書（漢字一致）→ 確定
2. 欧文名 → 前年の慣例「名　姓」（最後の語の前に全角空白）
3. それ以外 → JMnedictの候補に、既存Excelから学んだ「姓／名の漢字→読み」の頻度を加点し、
   索引のかな見出し・並び順と矛盾しない候補を採用。**すべて黄色（要確認）**

2026年は1,037人中201人が辞書で確定、692人（重複除く）が要確認になった。
索引で確実に分かるのは主に姓の頭文字まで（例：吉川えみ子が「き」の項→きっかわ系）。
ユーザー向けに重複をまとめた「読み確認リスト.xlsx」を別ファイルで渡した。
