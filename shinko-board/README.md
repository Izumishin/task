# 印刷進行ボード

外為印刷 電算編集室 ／ 仕様書「印刷進行ボード 仕様書」（2026年8月）の実装。

生産表スプレッドシートに Google Apps Script を紐づけ、下版から納品までの進行を社内で共有する
Webアプリです。**更新は工務担当者1名のみ**、**案件データは生産表から自動取込**、
**工務担当者の入力は日付のみ**、という3つの前提で作っています。

## ファイル

| ファイル | 内容 |
|---|---|
| `appsscript.json` | マニフェスト（タイムゾーン Asia/Tokyo／Webアプリは組織内限定） |
| `Code.gs` | 取込・データ読み書き・権限判定（サーバーサイド） |
| `Index.html` | ボード画面（HTML/CSS/JS 一体・外部ライブラリなし） |
| `tests/logic_test.js` | GAS APIをモックしてサーバー側ロジックを検証（`node tests/logic_test.js`） |

## 導入手順

1. 生産表スプレッドシート（ID `1yW4WyORgmAAzy-Clh6kafRK598pyY-Ee3OScoDXL1-A`）を開き、
   **拡張機能 → Apps Script** でスクリプトエディタを開く。
2. `Code.gs`・`Index.html` を貼り付ける（`clasp push` でも可）。
   マニフェストは「プロジェクトの設定 → appsscript.json をエディタで表示」を有効にしてから `appsscript.json` を反映。
3. **プロジェクトの設定 → スクリプト プロパティ** に編集者を登録する。

   | プロパティ | 例 | 説明 |
   |---|---|---|
   | `EDITOR_EMAILS` | `komu@example.co.jp` | 更新できる人。カンマ区切りで複数可。担当者交代はここを直すだけ |
   | `PRODUCTION_SS_ID` | （省略可） | 生産表を差し替えるとき。未設定なら仕様書のIDを使う |
   | `UNDECIDED_STALE_DAYS` | `14`（既定） | 「未定」のまま何日で注意表示を出すか |
   | `PRODUCTION_HEADER_ROWS` | `3`（既定） | 生産表の見出し行数（1行目=表題／2行目=工程見出し／3行目=項目名） |
   | `SRC_COL_ORDER_NO` | `M`（既定） | 受注番号の列 |
   | `SRC_COL_CUSTOMER` | `N`（既定） | 得意先の列 |
   | `SRC_COL_ITEM` | `O`（既定） | 品名の列 |
   | `SRC_COL_SALES` | `D`（既定） | 営業担当の列。取り込まないときは `-` |
   | `SRC_COL_DUE` | `W`（既定） | 納期の列 |
   | `SRC_COL_GEHAN_PLAN` | `-`（既定＝使わない） | 下版予定日の初期値に使う列。`AG` を入れると、生産表で予定が組まれている案件は下版予定日が入った状態で取り込まれる（**新規行のみ**。既存行は書き換えない） |

4. エディタで `setupBoardSheet` を実行 → `進行ボード` シートができる（初回は権限承認）。
5. `importFromProductionSheet` を実行 → 生産表から初回取込。
6. `createDailyImportTrigger` を実行 → 毎朝8時の自動取込トリガーを設定。
7. **デプロイ → 新しいデプロイ → ウェブアプリ**
   - 次のユーザーとして実行：**自分**（＝スプレッドシート所有者）
   - アクセスできるユーザー：**組織内のユーザー**

   発行されたURLを営業・工務・工場・配送に共有する。

スプレッドシートを開き直すと **「進行ボード」メニュー** が追加され、
シート作成・手動取込・トリガー設定をシートからも実行できます。

## 画面の使い方

- **未定バー（最上段）** … 取込直後の案件が並ぶ。工務担当者が営業に確認して
  `社内 / 社外 / 対象外` を1クリックで確定すると、その場でボード本体へ移動する。
  件数バッジは常時表示、閲覧専用ユーザーにはボタンが出ない。
- **3カラム** … 左=完了（納品完了から7日で自動非表示）／中央=今週（月〜金・日付ごと）／
  右=来週以降（日付ごと、最下部に「日程未定」）。カードは**現在工程の予定日**の位置に並ぶ。
- **完了 →** … 現在工程の完了日に今日を入れる（確認ダイアログなし）。
  カードは次工程の予定日へ自動で移動し、トースト内の **取消** で直前の1回だけ戻せる。
- **カードをクリック** … 編集パネル。各工程の予定日・完了日・メモ・外注スキップ・区分を編集。
  区分「社外」の案件では下版・印刷・外注の欄を表示しない。
- **検索・ジャンプ** … 受注NOの部分一致でハイライト＋スクロール、日付入力でその週へ移動、
  「今週へ」で戻る（`‹` `›` で前後の週へ）。
- **自動更新** … 30秒ごと。編集パネルを開いている間は止まる。

画面の操作に迷ったら、`進行ボード` シートを直接編集しても業務は止まりません
（区分はプルダウン、外注スキップはチェックボックス、日付は `yyyy/MM/dd` のテキスト）。

## 取込の動き

### 生産表のどの列を読むか

既定値は 2026年8月シートの構成に合わせてあります。

| 進行ボード | 生産表の列 | 備考 |
|---|---|---|
| 受注NO | M（受注番号） | 主キー |
| 得意先名 | N（得意先） | |
| 品名 | O（品名） | |
| 営業担当 | D（担当） | E〜H列は組版担当なので読まない |
| 納期 | W（納期） | |
| （任意）下版予定日 | AG（下版日） | 既定では読まない。Z〜AG に予定が組まれている運用なら `SRC_COL_GEHAN_PLAN` に `AG` を設定する |

見出しは3行（1行目=表題／2行目=入稿日・下版日・納品日などの工程見出し／3行目=項目名）、データは4行目から。

列がずれている／別の列を使いたい場合は、**コードを直さずスクリプトプロパティで変更**できます（上の表を参照）。
迷ったら `diagnoseImport` を実行すると、いま読んでいる列と実際に読めた値が実行ログに出ます。

毎朝8時（と手動ボタン）に、生産表の **一番右のシート** を読み、

1. 受注NOが未登録の行だけ A〜E 列を埋めて追記（区分は「未定」）
2. 既存行は B〜E 列（得意先・品名・営業担当・納期）のみ生産表に追随
3. **F列以降（工務が入力した値）は絶対に上書きしない**

差分だけを書くので、件数が増えても実行時間上限に当たりにくくしています。
書き込みは `LockService` で保護、日付は `Utilities.formatDate()` の `Asia/Tokyo` で統一。

案件の仕分け（社内／社外／対象外）は**自動判定しません**。品名や金額からの推測は実装していません。

## 仕様に明記がなく、実装側で決めた点

運用開始前に確認してください。いずれも仕様の方針に合わせたつもりですが、判断が入っています。

1. **納品工程の配置日は「納期」** … 仕様の列構成に「納品予定日」が無いため、
   現在工程が納品の案件は納期の位置に並べています。
2. **「遅れ」グループ** … 予定日が表示中の週より前で未完了の案件は、中央カラム最上部に
   「遅れ（予定日超過）」としてまとめました。これが無いとカードが画面から消えてしまうためです。
3. **土日の予定日** … 今週カラムは仕様どおり月〜金なので、土日の予定日は「来週以降」カラムに
   日付ごとに出ます。
4. **対象外の再表示** … 誤って「対象外」にした案件を戻せるよう、更新権限のある人だけに
   「対象外も表示」チェックボックスを置きました（既定はオフ＝画面から消える）。
5. **未定の滞留日数** … S列「最終更新日時」を起点に数えています（取込日＝作成日）。
6. **日付列はプレーンテキスト**（`yyyy/MM/dd`）で保持 … タイムゾーンによる日付ずれを避けるため。
   シートを直接編集して日付型で入力された場合も読み取れるようにしてあります。
7. **`EDITOR_EMAILS` 未設定時** … スクリプト所有者のみ更新可とし、画面上部に注意を表示します。
8. **生産表の見出し行は1行と仮定**（`PRODUCTION_HEADER_ROWS` で変更可）。

## うまくいかないとき

スプレッドシートの「進行ボード」メニュー、またはエディタから実行できます。

| 症状 | 実行する関数 | 内容 |
|---|---|---|
| 取込が0件になる／別の値が入る／どの列を読んでいるか知りたい | `diagnoseImport` | 実行ログにシート一覧・取込対象シート・見出し行（全行）・現在の列マッピング・その設定で読めた先頭3行・受注NOの件数を書き出す |
| 案件が1000行目付近から並んでしまった | `repairBoardSheet` | 空行を詰めて2行目から並べ直す（工務が入力した日付は保持） |

## テスト

スプレッドシートを使わずに、取込・工程遷移・権限まわりを検証できます。

```
node tests/logic_test.js
```

（GAS の `SpreadsheetApp` 等をモックし、`Code.gs` をそのまま読み込んで実行します）
