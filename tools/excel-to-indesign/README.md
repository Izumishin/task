# 保証人住所リスト Excel → InDesign データ結合用 変換ツール

Excel から CSV を書き出すと住所の番地が日付に化ける問題を解消し、
InDesign のデータ結合にそのまま流し込めるファイルを生成します。

## なぜ日付に化けるのか

元の .xlsx はすべてのセルが **文字列** として保存されているため、Excel 上では化けません。
問題が起きるのは次の 2 か所です。

1. **CSV を保存 → もう一度開いたとき**
   CSV はただのテキストで書式情報を持ちません。再度 Excel で開くと `4-35-20` が
   「2020年4月35日…」のように日付として自動解釈され、`2020/4/35` のような値に置き換わります。
2. **Excel の中で全角→半角変換をしたとき**
   `４－３５－２０`（全角）は日付に見えませんが、半角化した瞬間に `4-35-20` になり、
   標準書式のセルではその場で日付に変換されます。

つまり **半角化そのものが日付化のリスクを増やす** ため、書き出し形式とセットで対処する必要があります。
今回のデータでは変換後 **2,520 セル**（住所2行目・住所3行目）が該当しました。

| 誤変換の種類 | 件数 | 例 |
|---|---|---|
| 年-月-日と誤認 | 1,535 | `4-35-20` → 日付 |
| 月-日と誤認 | 842 | `748-7` → 7月48日 |
| 数値化（先頭0が消える） | 143 | `027` → `27` |

## 対処方針

データ側ではなく **ファイル形式側** で防ぎます。

- **InDesign は文字列としてしか読まないので、そもそも日付に化けません。**
  化けるのは Excel で開いたときだけです。
- そのため「InDesign へ渡す用」と「Excel で目視確認する用」を分けて出力します。
- CSV を Excel で開き直す運用は避けてください。開く必要がある場合は
  `_変換後_Excel確認用.xlsx`（全セル文字列書式）を使ってください。

## 変換内容

| # | 処理 | 備考 |
|---|---|---|
| 1 | 全角英数字 `０-９ Ａ-Ｚ ａ-ｚ` → 半角 | 記号・カナ・漢字は変更しません |
| 2 | ハイフン類 `－ ― ‐ – — −` → 半角 `-` | 住所・郵便番号の列のみ |
| 3 | 数字/英字に挟まれた長音符 `ー` → 半角 `-` | `2ー14ー39` → `2-14-39`。`コーポ`『アンバサダー』等の長音符は保持 |
| 4 | 前後の空白除去・連続空白の圧縮 | `大鐘　　直子` → `大鐘　直子` |
| 5 | 住所1行目の先頭にある都道府県名の重複を除去 | `東京都` + `東京都葛飾区金町` → `葛飾区金町` |

全角記号（`＆ （ ） ． ， ～`）は和文として残すか半角にするか判断が分かれるため
**自動変換せず、要確認リストに出力**しています。

## 出力ファイル

| ファイル | 用途 |
|---|---|
| `保証人住所_InDesign_UTF16タブ区切り.txt` | **InDesign 用（推奨）**。UTF-16LE + BOM / タブ区切り。Adobe が日本語データ結合で最も安定して読む形式。Excel で開いてもテキストインポートウィザードが立つので日付化しません |
| `保証人住所_InDesign_UTF8.csv` | 汎用 CSV。UTF-8 + BOM / 全項目クオート。**Excel でダブルクリックして開かないでください** |
| `保証人住所_変換後_Excel確認用.xlsx` | 全セルを文字列書式（`@`）で保存。Excel で開いても絶対に日付化しません |
| `保証人住所_要確認リスト.xlsx` | 目視確認が必要な行の一覧 |
| `保証人住所_変換ログ.csv` | 変換前後の全差分（どのセルをどう直したか） |

## 使い方

```bash
pip install openpyxl
python3 convert.py <入力.xlsx> [出力ディレクトリ]
```

## InDesign 側の設定

- **データソース**: `_UTF16タブ区切り.txt` を選択。
  「データソースを選択」で **［読み込みオプションを表示］にチェック** し、
  区切り文字＝**タブ**、エンコーディング＝**Unicode** を指定します。
- **空白行の削除**: 住所3行目は 3,091 件中 **2,057 件が空欄**です。
  データ結合パネルのオプションで **［空白フィールドの行を削除］** を有効にしてください。
  有効にしないと建物名のない住所で 1 行分の空きが出ます。
- **縦組みの場合は要注意**: 縦組みで半角数字を使うと数字が横倒しになります。
  縦組みのレイアウトなら、半角化せず全角数字のままにするか、
  縦中横（たてちゅうよこ）を設定する必要があります。今回は指定どおり半角で出力しています。
