# 名刺データ管理台帳

社員の名刺データ(下版PDF)を一覧管理し、営業が自分で最新PDFを取得できるようにするアプリです。
増刷のたびに発生していた「チャットで依頼 → 制作がPDFを渡す → 完了連絡」のやり取りをなくします。

- **営業**: 増刷は台帳から「最新PDF」をダウンロードするだけ。依頼が必要なのは「新規」「変更」のみ(依頼タブのフォームから)
- **制作**: 変更があったらInDesignを修正してPDFを「差し替え」。版数は自動で上がり、古いPDFは自動で消えるので、常に最新1つだけが取得されます

運用ルール全体の説明は [docs/名刺データ管理_運用フロー提案.md](docs/名刺データ管理_運用フロー提案.md) を参照してください。

---

## 1. 事前準備: Node.js を入れる(最初の1回だけ)

このアプリを動かすための土台となる無料ソフトです。

1. ブラウザで https://nodejs.org を開く
2. 緑色の「**LTS**」と書かれたボタンからインストーラーをダウンロード
3. ダブルクリックして、すべて「次へ」でインストール

WindowsもMacも手順は同じです。

## 2. アプリの入手

1. ブラウザで https://github.com/Izumishin/task を開く
2. 左上の「main」と書かれたプルダウンを押し、ブランチ `claude/business-card-workflow-1imlxw` に切り替える
3. 緑色の「**Code**」ボタン →「**Download ZIP**」
4. ZIPを解凍し、フォルダごと分かりやすい場所に置く(例: Windowsなら `C:\meishi`、Macなら書類フォルダ)

## 3. 起動する

フォルダの中の起動ファイルを**ダブルクリックするだけ**です。

- **Windows**: `start.bat`
- **Mac**: `start.command`
  - 初回に「開発元を検証できません」と警告が出た場合は、ファイルを**右クリック →「開く」→「開く」**で起動できます(2回目以降はダブルクリックでOK)

初回だけ「準備中(1〜2分)」の表示が出ます。
「サーバー起動: http://localhost:3000」と出たら、ブラウザで **http://localhost:3000** を開いてください。

> 黒い画面(ターミナル)は閉じるとアプリが止まります。**最小化してつけっぱなし**にしてください。

## 4. 使い方

### 制作(DTP担当)

1. 「台帳」タブ上部のフォームで社員を登録(氏名・ふりがな・部署・役職)
2. 各行の「**差し替え**」ボタンから下版PDFをアップロード(版数が自動で v01, v02… と上がります)
3. 依頼が来たら「依頼」タブで確認し、作業に合わせてステータスを「受付 → 制作中 → PDF支給済」と進める

### 営業

- **増刷(変更なし)**: 台帳で名前を検索 →「**⬇ 最新PDF**」ボタン。そのまま印刷手配してOK。制作への依頼は不要です
- **変更・新規**: 「依頼」タブのフォームから送信。「PDF支給済」になったら台帳からPDFを取得し、内容を確認して「完了」を押す

## 5. 別のPCへの引っ越し(試運転 → 本番PCへ移すとき)

台帳とPDFの全データは、アプリのフォルダ内の次の3つに入っています。

- `cards.json`(台帳)
- `requests.json`(依頼履歴)
- `uploads` フォルダ(PDF本体)

移行先のPCで手順1〜3を済ませたあと、**この3つを移行先のアプリフォルダにコピーするだけ**で、登録済みデータがそのまま引き継がれます。

## 6. 他のPCからアクセスするには

アプリを起動しているPCと同じ社内ネットワークにあるPCなら、ブラウザで
`http://(起動PCのIPアドレス):3000` を開くだけで同じ画面が使えます(例: `http://192.168.1.20:3000`)。

IPアドレスの調べ方(アプリを起動しているPCで):

- **Windows**: スタートボタン横の検索に `cmd` → 黒い画面で `ipconfig` と入力 → 「IPv4 アドレス」の数字
- **Mac**: システム設定 → ネットワーク → Wi-Fi(または有線)の「詳細」に表示されるIPアドレス

> つながらない場合は、起動PC側のファイアウォールで Node.js の通信許可を求められていないか確認してください(初回起動時に出るダイアログで「許可」を選べばOK)。

## 7. PC起動時に自動で立ち上げる(任意)

毎朝ダブルクリックするのも省きたい場合:

- **Windows**: `Windowsキー + R` → `shell:startup` と入力してEnter → 開いたフォルダに `start.bat` の**ショートカット**(右クリック→ショートカットの作成)を入れる
- **Mac**: システム設定 → 一般 → ログイン項目 →「+」で `start.command` を追加

## 8. バックアップのすすめ

アプリを動かしているPCが故障するとデータが消えるため、
**5章の3つ(`cards.json`・`requests.json`・`uploads`)を月1回、共有フォルダにコピー**してください。
なお名刺の元データ(InDesign)は制作の手元にあるため、最悪の場合も再構築は可能です。

## 補足(技術情報)

- 構成: Node.js + Express。データはJSONファイル保存(データベース不要)
- 手動起動: `npm install`(初回のみ)→ `npm start` → http://localhost:3000
- ログイン機能はありません。**社内ネットワーク限定**で使用してください
- 旧タスク管理アプリは http://localhost:3000/tasks.html に残っています
