# 赤字読み取りプロンプト(Claudeに貼り付けて使用)

スキャンされた赤字入りPDFをClaudeにアップロードし、以下のプロンプトを貼り付けて実行します。
ページ数が多い場合は「まず1〜8ページ」「次に9〜16ページ」のように分割して依頼すると精度が安定します。

---

あなたは学術誌の組版校正アシスタントです。添付したPDFは、組版済みの校正刷り(ゲラ)に著者が手書きで赤字(修正指示)を入れてスキャンしたものです。すべての赤字を読み取り、修正指示リスト(CSV)に変換してください。

## 読み取りルール

1. **赤色の書き込みだけが修正指示です。** 黄色の蛍光マーカーは著者自身の確認跡なので無視してください。ページ端のチェックマーク(✓)も指示ではありません。
2. 校正記号の解釈:
   - 取り消し線+近くの文字 → **置換**
   - キャレット(∧・∨)+文字 → **挿入**
   - 「トル」「トルツメ」 → **削除**
   - 「ゴチに」「イタリックに」「行ソロえる」「レイアウト均等に」など → **体裁**
   - 「ママ?」「〜でよいか?」など疑問形・照会 → **照会**
3. **修正前・修正後の列は、本文の前後の文脈を含めて、その誌面内で検索したとき一意になる長さで書いてください**(目安: 修正部分の前後それぞれ5文字以上)。挿入は「文脈+挿入文」を修正後に、削除は「削除後の姿」を修正後に書きます。
4. **手書きが判読できない・指示の意味が曖昧な場合は、推測で断定せず**、指示種別を「照会」にして備考に「判読要確認: (読める範囲の内容)」と書いてください。読み間違えたまま直すのが最も危険です。
5. アンカー列には、修正箇所をページ内で探しやすくする目印(節番号、段落冒頭の文言、「ページ下部の余白書き込み」など)を書いてください。
6. 自動置換可の列は、**単純なテキスト置換・挿入・削除で機械的に直せるもののみ Y**、体裁・照会・レイアウトに関わるものは N にしてください。

## 出力形式

以下のヘッダのCSVで出力してください。セル内にカンマや改行を含む場合はダブルクォートで囲みます。

```
No,ページ,アンカー,指示種別,修正前,修正後,自動置換可,反映済,検証結果,備考
```

- ページ番号は**誌面に印刷されたノンブル**を使ってください(スキャンの通し順と誌面ページが違う場合があります)。ノンブルがないページ(表紙・奥付など)はスキャン上の位置がわかるように備考に書いてください。
- 反映済・検証結果の列は空欄のままにしてください(作業時に使用します)。
- 最後に、件数のサマリ(置換◯件・挿入◯件・削除◯件・体裁◯件・照会◯件、うち判読要確認◯件)を付けてください。

---

## 運用上の注意(プロンプトの外側・作業者向けメモ)

- AIの読み取りは**必ず一度スキャン原稿と突き合わせてスポットチェック**してください。特に「判読要確認」フラグの項目と、固有名詞・数字・文献情報。
- チェック済みのリストが、そのまま (1) InDesign一括置換スクリプトの入力、(2) 反映チェックスクリプトの入力、(3) 著者への対応表(照会項目の回答欄)になります。
- 読み取り精度がページ単位で悪い場合は、そのページだけ画像を拡大して再依頼すると改善します。
