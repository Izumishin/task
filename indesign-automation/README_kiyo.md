# 紀要論文の自動組版スクリプト (kiyo_nagashikomi.jsx)

Word で書かれた論文原稿を、前回号の InDesign データと同じ体裁で自動的に組むスクリプトです。
前回号の紙面から次のことを**自動で学習**するので、スタイル名の設定は不要です。

- 段落の種類ごとの段落スタイル (題目・副題・著者名・所属・要旨・キーワード・大見出し・中見出し・
  本文・図表のタイトル・出典・注・参考文献 など)
- 「中見出しが続く大見出し」「表の出典の直後の本文」のような、前後関係による使い分け
- 本文の段落頭の全角スペース、見出し番号の書き方 (「1．はじめに」「2.1　…」)
- 注番号の書き方 (本文中「（2）」、注の欄「（ 1 ）＋タブ」、2 行目以降の字下げ)
- 注番号・副題のダーシ・「キーワード：」「出典：」の文字スタイル
- 「要　　旨」「《注》」「参考文献」の表記、空行の入れ方
- 表の体裁 (前回号の表をひな形として複製するので、表スタイル・セルスタイル・罫線・塗り・セル内の書体が
  引き継がれます。行や列の増減は中ほどで行うので、最後の行だけ下罫線が太い、などの体裁も崩れません)
- 句読点の使い分け (「、」か「，」か、「。」か「．」か)。原稿が違う方を使っていると、確認画面で
  統一するかどうかを聞きます。「．」→「。」は日本語の文の終わりだけで、見出し番号「1．」や小数は変えません
- 英数字と括弧の書き方 (全角か半角か)。確認画面の「文字の統一」で、全角英数字を半角に・半角括弧を全角に
  するかどうかを選べます (初期値は前回号の書き方)。URL・メールアドレスの中は変えません

## 使い方

1. 前回号の InDesign ファイルを**コピーして**、コピーを開く
2. 選択ツール (黒矢印) で**本文のテキストボックス**を1つクリックして選ぶ (どのページのものでも可)
3. スクリプトパネルで `kiyo_nagashikomi.jsx` をダブルクリックし、今回の Word 原稿 (.docx) を選ぶ
   - 題目・著者名・要旨が本文とは別のテキストボックスにある号では、その枠を探して選択した状態で
     「この枠に入れてよいですか?」と聞きます。違う枠なら「いいえ」で次の候補 (なければ本文の先頭) に
     なります。本文の途中のページにある枠・本文に埋め込まれた枠・図の説明の枠は候補にしません
4. 確認画面で、見出しなどの判定を確認する
   - 一覧には題目・見出し・図表などが表示されます (「本文・注・参考文献もすべて表示」で全段落)
   - 違っている行を選んで「選んだ段落の種類を変更」で直せます
   - 「種類ごとの段落スタイルを確認・変更…」で、種類ごとに使うスタイルを変えられます
5. 「流し込む」を押すと、原稿が流し込まれます
   - 文字があふれた分はページを自動で追加します (前回号の同じ側のページの枠を引き継ぎます)
   - 前回より短くなって空いたページは、確認のうえ削除できます
   - 柱などに入っている前回号の題目は、新しい題目に置き換わります
6. 仕上げに紙面を確認して保存

元に戻すときは「編集 > 取り消し」(完了画面に回数が表示されます)。

## Word 原稿について

- Word の「見出し 1」「見出し 2」スタイル、または「１．」「2.1」のような番号で見出しを判定します
- Word の**脚注**は InDesign の脚注として入ります (番号の書式は InDesign の脚注オプションに従います)
- Word の**文末脚注**は、出てくる順に番号を振り、参考文献の前に「《注》」としてまとめます
- **表の中の注**も取り込みます。脚注は表のセルの中に InDesign の脚注として入れ (番号は本文と通し)、
  文末脚注は本文と同じ書き方の注番号をセルに入れます。セルの中に脚注を入れられない場合は、表の直後に入れて知らせます
- Word の表はそのまま表に、図 (貼り込んだ画像) は InDesign ファイルと同じ場所の
  `Links` フォルダに書き出して配置します
- 題目と副題は、題目の段落の中の改行で分けます
- Word の**箇条書き・段落番号** (「・」「1.」「（1）」「①」「ア．」など Word が自動で付けているもの) は、
  Word の番号の設定を読んで、同じ記号・番号を文字として段落の頭に入れます
  - 入れ子 (「2.1」など)、番号の振り直し・続き、見出しスタイルに付いた自動番号にも対応します
  - 記号の箇条書きの Symbol 書体の特別な文字は、「•」「●」「■」などふつうの記号にします
  - 番号と本文の間は、全角の記号・番号 (「（１）」「①」など) の後は詰め、半角の後は半角スペースにします
  - 箇条書きの段落は「箇条書き」の種類になります。名前に「箇条」「リスト」を含む段落スタイルがあれば
    それを、なければ本文のスタイルを使います (確認画面で変えられます)。段落頭の全角スペースは付けません
- Word で付けた**文字の飾り** (イタリック・太字・下線・上付き・下付き・圏点・取り消し線・ルビ) は、
  Word でスタイル登録していなくても読み取り、InDesign の文字スタイルを当てます
  - どの文字スタイルを使うかは、文字スタイルの設定 (書体が Italic、下線あり、圏点あり、ルビあり など)
    から自動で選び、確認画面の「文字の飾りに使う文字スタイルを確認・変更…」で変えられます
  - ルビの文字は、その文字に直接付けます (ルビ用の文字スタイルがあればそれも当てます)
  - 題目・見出しの全体にかかった太字・斜体は、段落スタイルに任せて当てません
  - 斜体は、欧文の部分と和文の部分を自動で分けます。欧文は「イタリック」、和文は「和文の斜体」
    (歪みを付けた文字スタイルなど) の文字スタイルを当てます。和文の書体にはイタリックがないため、
    和文の斜体を欧文のイタリックで代用することはしません
  - 「イタリック＋太字」「イタリック＋下線」などの組み合わせは、原稿に出てきたものだけを一覧にして、
    どの文字スタイルを使うかを選べます (両方の設定を持つスタイルがあれば自動で選びます)。
    組み合わせを選ばなかった場合は、上付き・下付き → 斜体 → 太字 … の順で1つだけ当てます
  - 選んだ文字スタイルは InDesign ファイルに記録され、次号 (このファイルのコピー) でも使われます
  - 下線は線種ごとに分けて扱います (下線・下二重線・太い下線・下点線・下破線・下一点鎖線・下二点鎖線・
    下波線・下二重波線)。取り消し線も「取り消し線」「二重取り消し線」に分けます。太さだけ違う線種
    (太い点線など) は同じ種類にまとめます
  - 下二点鎖線の文字スタイルがないときは、下一点鎖線 → 下線 の順で代用します
  - Word の蛍光ペンも「蛍光ペン」として読み取ります (自動では文字スタイルを選びません。注番号の文字スタイルを
    当てる、などの使い方ができます)
  - 表のセルの中の飾りも取り込みます (1行目のセル全体の太字は、見出し行の書式なので表の体裁に任せます)
  - InDesign の文字スタイルの下線の「線の種類」(点線・破線・波線・細-細 など) と太さから、線種ごとの
    文字スタイルを自動で選びます。その線種の文字スタイルがないときは、ふつうの下線 (取り消し線) の
    文字スタイルで代用します

- Word の**数式** (「挿入 > 数式」で作ったもの) は、1行の文字にして入れます
  - 添字・指数は下付き・上付き (文字の飾りと同じく文字スタイルを当て、なければ文字に直接設定)
  - 書体は原稿どおり (Word で立体なら立体、指定がなければ欧文・ギリシャ文字だけイタリック)
  - 「=」「+」「−」の前後は四分アキ、ハイフンはマイナス記号 (−) にします
  - 別の行に立てた式は「数式 (別行)」の種類になります。名前に「数式」を含む段落スタイルがあればそれを、
    なければ本文のスタイルで中央揃えにします (確認画面で変えられます)
  - 縦に組む分数・Σ の上下の範囲・行列など、1行では元の形にならない式は、確認画面に【要仕上げ】と出します
  - **Windows では、その式を Word で PDF にして配置できます** (流し込む前に聞きます)
    - スクリプトが Word を裏で起動し、式を1つずつ PDF にして `Links` フォルダに
      「原稿名_数式01.pdf」の名前で保存し、式の段落に配置します (余白は切り抜きます)
    - 式の文字の大きさは「数式 (別行)」の段落スタイルの文字の大きさに合わせます。
      書体は Word の数式用書体 (Cambria Math) です
    - PDF を自分で作り直すときは、同じ名前で上書き保存して、リンクパネルで「リンクを更新」してください。
      次に流し込むとき、前に作った PDF があれば「そのまま使うか、作り直すか」を聞きます
    - 式番号など式以外の文字がある段落、PDF にできなかった式、Mac では、文字の式で入れて付箋
      (印刷されないメモ) を付けます。分数は「(分子)/分母」の形で入ります
  - 数式の中の括弧は、「半角括弧を全角に」でも変えません
  - MathType・数式エディタ 3.0 で作った式は、まだ取り込めません
- 英文の原稿では、「半角括弧を全角に」の初期値をオフにします

## 取り込まないもの (手作業で確認)

- 表の中の表にある注 (Word の脚注・文末脚注)
- 英文要旨 (原稿に含まれていないことが多いため、前回号のまま残ります)
- 偶数ページの柱の号数・開始ページ番号

## うまくいかないとき

- 流し込みの途中でエラーが出たときは、エラーの画面に「止まった所」(例: 「本文 / 表の作成 (後ろから 2 個目)」)
  が表示されます。その画面をそのまま送ってください
- 表や図の一部だけでエラーが出た場合は、流し込みを止めずに、完了画面に「[注意]」として表示します
- 枠に入りきらない大きな表や図があると、ページの追加を途中で止めます (空のページが延々と増えないように)

## 開発者向け

InDesign に依存しない部分 (docx の読み取り・段落の判定・体裁の学習・流し込み用テキストの組み立て) は
Node.js でテストできます。テストは架空の原稿を内部で生成して使うので、実際の原稿は不要です。

```bash
node test/kiyo_tests.js
# 実際の原稿でも確かめる場合
KIYO_DOCX=原稿.docx node test/kiyo_tests.js
```
