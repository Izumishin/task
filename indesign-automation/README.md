# 大会ポスター 自動流し込みスクリプト

毎年の学会大会ポスター(InDesign)に、Word 原稿の文言を自動で流し込むスクリプトです。
昨年のポスターの体裁(段落スタイル・タブ・「〈 〉」などの記号の使い方)を保ったまま、
テキストだけを今年の内容に置き換えます。

## 自動で置き換わるもの

| 項目 | 例 |
|---|---|
| 大会回数 | 第43回 → 第44回 (タイトルの大きな数字も含めドキュメント全体) |
| 開催日 | 令和7年◯月◯日（◯） → 令和8年9月5日（土） |
| 各セクションの時刻 | 受付開始・開会の辞・研究発表・休憩・基調講演・閉会の辞・懇親会 |
| 開会の辞/閉会の辞の担当者 | 会長・理事長の名前と肩書き |
| 各発表の時間・タイトル・発表者・司会者 | 6件の研究発表 + 基調講演 |
| タイトルの副題 | 「—◯◯—」部分を副タイトル用の段落に自動で振り分け |
| 懇親会情報 | 会場住所・会費・申込締切 |

## 自動では置き換わらないもの (実行後に目視確認)

- 会場名・住所・〒 (タイトル部) … 会場が変わった年は手動で修正
- 学会事務局の住所・E-mail・ホームページ
- タイトル内のイタリック等の文字単位の装飾 (欧文タイトルなど)
- 発表件数が昨年と違う場合の枠の増減 (レポートに警告が出ます)

## 初回のみ: スクリプトのインストール

1. InDesign のメニュー **ウィンドウ > ユーティリティ > スクリプト** でスクリプトパネルを開く
2. 「ユーザー」フォルダを右クリック → **Finder/Explorer で表示**
3. 開いたフォルダ(`Scripts Panel`)に `word_to_indesign.jsx` をコピー

## 使い方は2通り

### A. 1つずつ置き換えモード (確実。まずはこちらがおすすめ)

1. 昨年のポスター(.indd)を**コピーして**、コピーの方を InDesign で開く
2. **選択ツール(黒矢印)で置き換えたいテキストボックスをクリックして選択**
3. スクリプトパネルで `word_to_indesign.jsx` をダブルクリックし、今年の Word 原稿(.docx)を選ぶ
4. ダイアログが開きます:
   - 左 = 選択したボックスの段落 / 右 = 原稿の行 (最も近い行が自動で選ばれます)
   - 下の欄で置き換え後のテキストを確認・修正して **「置き換えて次へ」**
   - 時刻の「〈 〉」やタブなど紙面側の体裁は自動で維持されます
5. ボックスが終わったら「終了」→ 次のボックスを選択して再実行

### B. 全自動モード

テキストボックスを**選択せずに**スクリプトを実行すると、ページ上のすべての
テキストボックスを位置順(上→下)に処理します。実行後にレポート
(`流し込みレポート_◯◯.txt`)の `[警告]` を確認し、残った箇所はモードAで仕上げてください。

原稿ファイルについて (共通):
- .docx をそのまま選べます (Windows・Mac 共通。スクリプトが直接読み込みます)
- .txt も可 (UTF-8 / UTF-16 / Shift-JIS を自動判別)
- 旧形式の .doc のみ非対応 → Word で .docx に保存し直してください

実行直後であれば **編集 > 取り消し** 1回で流し込み前の状態に戻せます。

## Word 原稿の書き方 (この形式なら自動で認識されます)

これまでどおりの原稿の書き方で動くように作ってあります。ポイントは:

- 時間は `＜10:30－11:00＞` の形式 (`＜＞` `〈〉` `<>`、`－` `–` `-` の揺れはOK)
- 発表は「時間の行 → タイトルの行 → 発表者の行 → 司会者の行」の順
- 発表者・司会者は `発表者　名前（所属）` の形式 (1行にまとめても、別々の行でもOK)
- セクション名は行頭に: 受付開始 / 開会の辞 / 研究発表 / 小休憩 / 昼食休憩 / 休憩 /
  基調講演 / 閉会の辞 / 懇親会 / 学会事務局

## うまくいかないとき

- **「プログラム本文のストーリーが見つかりません」** … 開いているドキュメントが
  大会ポスターか確認してください
- **一部だけ置き換わらない** … レポートの `[警告]` 行に理由が出ます。該当箇所のみ
  手動で修正すれば OK です
- **「原稿を解析できませんでした」** … ダイアログに「読み取った内容の先頭」が
  表示されます。文字化けしている場合や原稿と違う内容の場合は、.docx を
  そのまま選び直してください
- **.docx が読めない** … Word の「名前を付けて保存」で .docx 形式のまま保存し直すか、
  「書式なし(.txt)」で保存してそちらを選んでください

## 開発者向け

文字列処理のコア部分(原稿の解析・置換ロジック)は InDesign 非依存で、
Node.js でテストできます:

```bash
node test/run_tests.js
```

`test/sample_manuscript.txt` は第44回大会の Word 原稿から書き出したサンプルです。
