# 柱をWordファイル名から自動設定するスクリプト（InDesign用）

各ページに配置したPDFのファイル名（＝Wordのファイル名）を読み取り、柱に自動で流し込みます。
例：`01_学則.pdf` → 柱「学則」

## 準備（最初に1回だけ）

1. `柱をファイル名から自動設定.jsx` をInDesignのスクリプトフォルダに入れる
   - ［ウィンドウ］→［ユーティリティ］→［スクリプト］を開く
   - 「ユーザー」フォルダを右クリック →［エクスプローラーで表示］→ そこへコピー
2. 親ページの柱テキストフレームを選択し、［ウィンドウ］→［ユーティリティ］→［スクリプトラベル］で `柱` と入力
   - 見開きの親ページなら、左右両方のフレームに付けます
   - 柱フレームの段落スタイル・位置はこれまでどおりでOK（文字だけが置き換わります）

## 使い方

1. PDFをこれまでどおり1ページずつ配置する
2. スクリプトパネルで `柱をファイル名から自動設定.jsx` をダブルクリック
3. 完了メッセージが出たら、デスクトップの `柱設定ログ.txt` で結果を確認

- 複数のドキュメントを開いていると「すべてに適用しますか？」と聞かれます
- PDFがないページ（目次・扉など）は何もしません
- 何度実行しても上書きされるので、PDF差し替え後に再実行してもOK
- 失敗したら Ctrl+Z 1回で元に戻せます

## ファイル名の加工ルール

| ファイル名 | 柱 |
|---|---|
| `01_学則.pdf` | 学則 |
| `1-学則.pdf` / `001 学則.pdf` / `０１．学則.pdf` | 学則 |
| `2024年度方針.pdf` | 2024年度方針（区切りがないので削らない） |

ルールを変えたいときは、スクリプト冒頭の `PREFIX_PATTERN` を編集してください。

## 注意

- 1ページにPDFが2つ以上あるときは、1つ目のファイル名を使い、ログに「要確認」と出します
- 柱フレームは「オーバーライド」されます。あとで親ページの柱の位置や書式を変えても、オーバーライド済みのページには反映されないので、その場合はページを選んで［親ページ項目のオーバーライドを削除］してから再実行してください
