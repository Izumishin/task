# 校規集 組版サポートツール

| ファイル | 用途 |
|---|---|
| `目次索引ページ自動入力.jsx` | 細目次・索引のページ数（仮の「●」）を、本文から自動で入力する InDesign スクリプト |
| `校規集チェックツール.html` | 完成PDFで「細目次・索引のページ ↔ 柱」「ノンブルの連番」を照合するブラウザツール |

柱は従来どおり親ページで作成します（Word のヘッダー【格付けタグ】は PDF に残す）。

---

## 1. 目次索引ページ自動入力.jsx

本文に配置したPDFのファイル名（例：`13【機２総（教職員限り）】職員研修に関する規程.pdf`）から各規程の開始ページを調べ、
細目次・索引の「○題名……●　上」の「●」をページ数に置き換えます。

### 準備（最初に1回）
［ウィンドウ］→［ユーティリティ］→［スクリプト］を開き、「ユーザー」フォルダを右クリック →［エクスプローラーで表示］→ そこへ `目次索引ページ自動入力.jsx` をコピー。

### 使い方
1. 本文のInDesignファイル（上巻・下巻）を開く
2. 細目次・索引のInDesignファイルを開き、そのウィンドウを前面にする
3. スクリプトパネルで `目次索引ページ自動入力.jsx` をダブルクリック
4. 件数の確認が出るので［はい］
5. デスクトップの `目次索引ページ入力ログ.txt` で「要確認」の行をチェック

### しくみ・ルール
- 「○」「〇」で始まる段落の、最後の区切り（タブ・右インデントタブ・リーダー）から「上／下」の手前までをページ数に置き換えます（「●」・空欄・昨年の数字のどれでも可）。「上」「下」や書式はそのまま
- 題名が長く2行に分かれていても1項目として扱います
- 照合は次の順に試します（全角／半角、空白、題名途中の改行は無視）
  1. ファイル名から番号と【タグ】を除いた題名と一致
  2. ファイル名の括弧書き（例：`(令和2年7月改正)`）を除いて一致
  3. 柱の文字と一致（`付　録（明治大学健康保険組合規約）` のような柱は括弧の中も照合）
  4. 部分一致（候補が1つだけのとき。ログに「要確認」と表示）
  - 各段階で「学校法人明治大学」「明治大学付属明治」「明治大学」の有無だけの違いも一致とみなします
  - 編名など複数の規程で共通の柱は照合に使いません
- 照合できない行は書き換えません（ログに「要確認」）
- 本文ファイル名に「上」「下」が入っていれば、行の「上／下」と食い違うものもログに出します
- Ctrl+Z 1回で元に戻せます
- デスクトップに `規程開始ページ一覧.txt`（タブ区切り。Excelに貼り付け可）も保存します

## 2. 校規集チェックツール.html

完成PDFを読み込み、次を照合します。PDFはパソコン内だけで処理し、外部へは送信しません（pdf.js の取得にインターネット接続が必要）。

| チェック | 内容 |
|---|---|
| 細目次 ↔ 柱 | 細目次のページの柱が、その題名になっているか。開始ページのずれも検出 |
| 細目次にない規程 | 柱が切り替わる（＝規程が始まる）のに、細目次に載っていないもの |
| 索引 ↔ 本文 | 索引の規程名が、載っているページの本文にあるか |
| ノンブル連番 | ページ番号の飛び・重複（白ページの隠しノンブル分は正常扱い） |

### 使い方
1. `校規集チェックツール.html` をダブルクリック（Chrome / Edge）
2. 完成PDFをドロップ（上巻・下巻をまとめて入れてOK）
3. 各PDFの「細目次のページ」「索引のページ」をPDFビューアのページ番号で入力（例：`3-14`）
4. ［チェック開始］→ 結果を確認。［CSVで保存］でExcel用の一覧も出せます

### うまく読み取れないとき
- 「ページ一覧（検出確認用）」タブで柱とノンブルが正しく拾えているか確認し、ずれていたら［詳細設定］で調整
- 索引の「見つからない」は、題名が本文中で改行・分断されている場合にも出ることがあります。最終確認は目視で
