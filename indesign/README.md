# 柱をWordファイル名から自動設定するスクリプト（InDesign用）

各ページに配置したPDFのファイル名（＝Wordのファイル名）を読み取り、柱に自動で流し込みます。
例：`13【機２総（教職員限り）】職員研修に関する規程.pdf` → 柱「【機２総（教職員限り）】職員研修に関する規程」

## 準備（最初に1回だけ）

1. `柱をファイル名から自動設定.jsx` をInDesignのスクリプトフォルダに入れる
   - ［ウィンドウ］→［ユーティリティ］→［スクリプト］を開く
   - 「ユーザー」フォルダを右クリック →［エクスプローラーで表示］→ そこへコピー
2. 親ページの柱テキストフレームを選択し、［ウィンドウ］→［ユーティリティ］→［スクリプトラベル］で `柱` と入力
   - 見開きの親ページなら、左右両方のフレームに付けます
   - 柱フレームの段落スタイル・位置はこれまでどおりでOK（文字だけが置き換わります）

## 使い方

1. PDFをこれまでどおり1ページずつ配置する
2. スクリプトパネルで `柱をファイル名から自動設定.jsx` をダブルクリック
3. 完了メッセージが出たら、デスクトップの `柱設定ログ.txt` で結果を確認

- 複数のドキュメントを開いていると「すべてに適用しますか？」と聞かれます
- PDFがないページ（目次・扉など）は何もしません
- 何度実行しても上書きされるので、PDF差し替え後に再実行してもOK
- 失敗したら Ctrl+Z 1回で元に戻せます

## ファイル名の加工ルール

| ファイル名 | 柱 |
|---|---|
| `13【機２総（教職員限り）】職員研修に関する規程.pdf` | 【機２総（教職員限り）】職員研修に関する規程 |
| `01_学則.pdf` | 学則 |
| `1-学則.pdf` / `001 学則.pdf` / `０１．学則.pdf` | 学則 |
| `2024年度方針.pdf` | 2024年度方針（区切りがないので削らない） |

ルールを変えたいときは、スクリプト冒頭の `PREFIX_PATTERN` を編集してください。

## 注意

- 1ページにPDFが2つ以上あるときは、1つ目のファイル名を使い、ログに「要確認」と出します
- 柱フレームは「オーバーライド」されます。あとで親ページの柱の位置や書式を変えても、オーバーライド済みのページには反映されないので、その場合はページを選んで［親ページ項目のオーバーライドを削除］してから再実行してください

# 完成PDFのチェックツール（校規集チェックツール.html）

完成したPDFを読み込み、次の3つを自動で照合します。

| チェック | 内容 |
|---|---|
| 細目次 ↔ 柱 | 細目次の「題名 …… ページ」のページの柱が、その題名になっているか（柱のタグ【…】は除いて比較）。開始ページずれも検出 |
| 細目次にない規程 | 柱が切り替わる（＝規程が始まる）ページで、細目次に載っていないもの |
| 索引 ↔ 本文 | 索引の「語句 …… ページ」の語句が、そのページの本文に実際にあるか |
| ノンブル連番 | ページ番号の飛び・重複（白ページの隠しノンブル分は正常扱い） |

## 使い方

1. `校規集チェックツール.html` をダブルクリックしてブラウザ（Chrome / Edge）で開く
   - PDFの読み込み部品をネットから取得するため、インターネット接続が必要です
   - PDF自体は外部に送信されません（パソコン内だけで処理）
2. 完成PDFをドロップ（上巻・下巻をまとめて入れてOK）
3. 各PDFの「細目次のページ」「索引のページ」をPDFビューアのページ番号で入力（例：`3-12`）
4. ［チェック開始］→ 結果を確認。［CSVで保存］でExcelで開ける一覧も出せます

## うまく読み取れないとき

- まず「ページ一覧（検出確認用）」タブで、各ページの柱とノンブルが正しく拾えているか確認
- ずれていたら［詳細設定］で調整
  - 柱を探す範囲（上端から何%か）／ノンブルを探す範囲（上下端から何%か）
  - 細目次・索引の段数（2段組なら 2）
- 索引の「見つからない」は、語句が改行や表の中で分断されている場合にも出ることがあります。最終確認は目視でお願いします
