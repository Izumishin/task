# はがき宛名 2 行入れ替えスクリプト（InDesign）

## やりたいこと

| | 変更前 | 変更後 |
|---|---|---|
| 上の行（大きいスタイル） | 末吉　遥貴　様 | 末吉　康志　様　保証人様 |
| 下の行（小さいスタイル） | （末吉　康志　様　保証人様） | （末吉　遥貴　様） |

## 考え方

**段落を動かすのではなく、2 行の「文字列だけ」を入れ替えます。**

段落スタイルは行の位置に貼りついたまま動かないので、

- 上に来た「末吉　康志　様　保証人様」→ 今の「末吉　遥貴　様」のスタイル（大きい方）
- 下に来た「末吉　遥貴　様」→ 今の「末吉　康志　様　保証人様」のスタイル（小さい方）

というご要望が、文字を入れ替えるだけで自動的に満たされます。
段落スタイルを付け替える必要も、テキストフレームやセルを動かす必要もありません。

### 対応レイアウト

- 2 行が同じテキストフレームに並んでいる
- 2 行が別々のテキストフレームに分かれている
- **2 行が表（テーブル）の別々のセルに入っている**（入れ子の表も可）
- 片方がセル、もう片方がテキストフレーム

> InDesign の `story.paragraphs` は表のセルの中身を含みません。
> そのためセル内テキストは Story とは別の「入れ物」として個別に走査しています。
> 組は ①同じフレーム／セルの中 → ②同じ表の中 → ③同じページの中 の順で作ります。

## ファイル

| ファイル | 用途 |
|---|---|
| `01_inspect_styles.jsx` | どの行にどの段落スタイルが当たっているかを調べる（何も書き換えない） |
| `02_swap_name_lines.jsx` | 本体。開いているドキュメントの全ページを一括で入れ替える |
| `03_batch_folder.jsx` | `.indd` が複数ファイルに分かれている場合のバッチ処理（1 ファイルに 3000 ページなら不要） |

## 手順

### 0. 準備
必ず **元ファイルのコピー** で作業してください。

スクリプトの置き場所（どちらでも可）:
- Windows: `C:\Users\<ユーザー名>\AppData\Roaming\Adobe\InDesign\<バージョン>\ja_JP\Scripts\Scripts Panel\`
- Mac: `~/Library/Preferences/Adobe InDesign/<バージョン>/ja_JP/Scripts/Scripts Panel/`

InDesign の **[ウィンドウ] → [ユーティリティ] → [スクリプト]** パネルに表示されます。

### 1. スタイル名を調べる
ドキュメントを開いた状態で `01_inspect_styles.jsx` をダブルクリック。
デスクトップに `indesign_style_report.txt` が出ます。表で組んである場合は
`◆ 表 1` → `● セル 0 (1行1列)` のようにセル単位で中身が出るので、
「末吉　遥貴　様」の行のスタイル名と「（末吉　康志　様　保証人様）」の行のスタイル名を控えます。

### 2. 設定する
`02_swap_name_lines.jsx` をテキストエディタで開き、冒頭の `CONFIG` を編集します。

```js
STYLE_TOP:    "学生氏名",     // ← 今「上」にある 末吉　遥貴　様 のスタイル名
STYLE_BOTTOM: "保証人氏名",   // ← 今「下」にある （末吉　康志　様　保証人様） のスタイル名
PAREN_POSITION: "bottom",     // カッコの扱い（下記参照）
DRY_RUN: true,                // まずは true のまま
```

`PAREN_POSITION` の選択肢:

| 値 | 結果 |
|---|---|
| `"bottom"`（既定） | 上: `末吉　康志　様　保証人様` / 下: `（末吉　遥貴　様）` ※今のデザインを踏襲 |
| `"top"` | 上: `（末吉　康志　様　保証人様）` / 下: `末吉　遥貴　様` |
| `"none"` | カッコを両方とも外す |
| `"keep"` | カッコごと丸ごと入れ替える（文字列を一切加工しない） |

### 3. 下見（DRY RUN）
`DRY_RUN: true` のまま `02_swap_name_lines.jsx` を実行。
**1 文字も書き換えません。** デスクトップの `indesign_swap_log.txt` に

```
[1 ページ]
   上 : 末吉　遥貴　様            →   末吉　康志　様　保証人様
   下 : （末吉　康志　様　保証人様） →   （末吉　遥貴　様）
```

のように「何件が、どう変わるか」が出ます。件数がページ数とだいたい合っているか確認してください。

### 4. 本番
`DRY_RUN: false` にして再実行。全ページまとめて入れ替わります。
処理は 1 つの取り消し単位にまとめてあるので、**[編集] → [取り消し] 一発で全部戻せます。**

## 注意点

- **文字スタイル**（行の一部だけ色を変えている等）を当てている場合、その行の先頭の書式に統一されます。段落スタイルだけで組んでいれば影響ありません。
- 対象行に**ルビ・分割禁止・カーニング等の局所設定**を手で入れている場合も同様に、行頭の設定に揃います。
- ロックされたレイヤー／フレームがあるとその行だけ失敗します。ログの「エラー」欄に出るので、ロックを外して再実行してください。
- オーバーセット（あふれ）テキストは処理されますが、ページ番号が「(不明)」と出ます。
- スタイル名を空 `""` のままにすると **自動判定モード**（「保証人」を含む行＝下、同じ組のもう一方の「様」を含む行＝上）で動きます。まずは DRY RUN で結果を必ず確認してください。

## データ結合（データマージ）で作っている場合

元データが CSV／TXT ＋ テンプレートの **データ結合** なら、生成済みの 3000 ページに対して
このスクリプトを流しても構いませんが、**テンプレート側でプレースホルダ
（`<<学生氏名>>` と `<<保証人氏名>>`）を入れ替えて結合し直す方が確実です。**
その場合も「枠は動かさず、差し込むフィールド名だけを上下で入れ替える」のが同じ考え方になります。

## 動作検証について

`test/test_swap.js` は InDesign の DOM を Node.js 上で模擬して
`02_swap_name_lines.jsx` のロジックだけを検証するテストです（InDesign 不要）。

```
node indesign/test/test_swap.js
```

- 同じフレーム／別フレーム／**表の別セル**／セルとフレームの混在
- カッコの扱い 4 パターン
- 自動判定モード
- DRY RUN で 1 文字も変わらないこと
- 表レイアウトの 3000 ページで 3000 件処理できること
- 住所など対象外のセルが書き換わらないこと

を確認しています。
